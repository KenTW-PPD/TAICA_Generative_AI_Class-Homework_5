# TAICA_生成式AI：文字與圖像生成的原理與實務_作業 ： 可愛踩地雷網頁

## 介紹：
本專案為生成式AI課程作業，使用 **Vibe Coding** 製作出一可**互動**的網頁。   
整個網頁內容皆整合至 `index.html` 檔案中，包含：      
- HTML 網頁結構
- CSS 網頁格式
- JavaScript 網頁功能       
## 網頁功能：
此網頁功能為簡單的踩地雷小遊戲製作，    
介面語言為繁體中文，共有三個官方難度(初級9×9 10個地雷、中級16×16 40個地雷、高級16×30 99個地雷)，並附帶音效。    
在介面上即時顯示進行秒數與現在剩餘地雷數 (總地雷數量 - 目前插旗數量)，遊戲結束時可直接重新開啟一場遊戲。
## 操作方式：
**滑鼠使用：**
- **左鍵**點擊開格
- **右鍵**點擊插旗  

**手機使用：**
- 手指**點擊**開格
- 手指**長按**插旗  

**鍵盤使用：**
- **方向鍵(上下左右)**移動藍色虛線(現在位置)
- **空白鍵**開格
- **F鍵**插旗
## Vibe Coding：
本專案使用 **Vibe Coding** 方式開發，使用 AI 依照要求設計網頁與程式碼撰寫。     
開發過程中使用 AI 協助：
- 網頁介面設計
- HTML 結構撰寫
- CSS 樣式設計
- JavaScript 功能實作
- 程式錯誤修正
- 網頁功能優化      

在 AI 協助產生程式碼後，再由本人進行測試。
## Vibe Coding 開發流程：
1. 與 AI 討論網頁功能目的
2. 與 AI 討論網頁介面設計
3. 將上述內容轉換成網頁規劃書
4. 將規劃書交給 AI 進行 Vibe Coding
5. 人工驗證網頁功能
